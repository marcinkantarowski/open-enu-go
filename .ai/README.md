# `.ai/` - what an agent reads

([ADR-0027](platform/adr/0027-platform-and-project-knowledge-are-separate-trees.md)).
`.project.json` says `"initialized": false` in the platform's own repository, so the project
side here stays empty apart from these indexes and the generated inventory.
