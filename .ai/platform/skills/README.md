# Skills

End-to-end checklists that turn a convention into a procedure. Vendor-neutral; an agent's
own skill directory can link here.

| Skill | Use it when |
|-------|-------------|
| [`create-module`](create-module.md) | adding a feature - backend module, frontend layer, permissions, tests, docs, migration, Task Router row |
| [`add-endpoint`](add-endpoint.md) | adding an operation - the spec first, the generated server, a permission, a command, a test, the types |
| [`review-change`](review-change.md) | before proposing anything - the checklist a change must pass |

A skill is a procedure, not a reference. Where it needs to explain *why*, it links to
[`../docs/`](../docs/README.md) rather than restating it, so there is one copy to keep true.
